# Portfólio · Alice Sombra

React + Vite + TypeScript + Tailwind (v3).

## Rodar no VS Code
 
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera a pasta dist/
npm run preview  # testa o build
```



| O que | Arquivo |
|---|---|
| Nome, textos, contatos, links | `src/data/profile.ts` |
| Projetos (e links Case/GitHub/Site) | `src/data/projects.ts` |
| Experiência e formação | `src/data/experience.ts` |
| Tecnologias | `src/data/tech.ts` |
| Cores dos temas claro/escuro | `src/index.css` (variáveis) |
| Paleta fixa da marca | `tailwind.config.ts` |
| Currículo (PDF) | `public/curriculo-alice-sombra.pdf` |
| Foto e mascote | `src/assets/` |
